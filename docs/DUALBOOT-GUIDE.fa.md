# نصب Saman OS کنار ویندوز (دوال‌بوت)

با این روش Saman OS روی همان دیسکی که ویندوز هست نصب می‌شود، بدون اینکه
ویندوز یا فایل‌هایش پاک شود. از آن به بعد، هر بار که سیستم را روشن می‌کنی
منوی بوت می‌آید و انتخاب می‌کنی: **Saman OS** یا **Windows**.

## چیزهایی که لازم داری

1. فایل ISO زندهٔ Saman OS، نوشته‌شده روی یک فلش USB (با Rufus در حالت DD
   یا با balenaEtcher).
2. حداقل ۲۴ گیگابایت فضای خالی روی دیسک (برای استفادهٔ روزمره ۴۰ گیگابایت
   یا بیشتر بهتر است).
3. خاموش‌بودن **Secure Boot** در تنظیمات UEFI سیستم (بوت‌لودر فعلی Saman OS
   امضای مایکروسافت ندارد؛ روی سیستم خودت و با مسئولیت خودت).

## قدم‌ها

### ۱) در ویندوز جا باز کن

- در ویندوز، **Disk Management** را باز کن (راست‌کلیک روی دکمهٔ Start).
- روی درایو C راست‌کلیک کن و **Shrink Volume** را بزن.
- حداقل ۱۲٬۰۰۰ مگابایت (بهتر: ۳۰٬۰۰۰) کم کن. فضای «Unallocated» که ساخته
  می‌شود را **دست نزن**؛ نه پارتیشن بساز، نه فرمت کن. نصاب Saman OS خودش
  از همان فضا استفاده می‌کند.

### ۲) بوت از فلش

- سیستم را راه‌اندازی مجدد کن و با فلش بوت شو (معمولاً با F12 یا F8 منوی
  بوت می‌آید؛ گزینهٔ فلش را انتخاب کن).
- در منوی Saman OS گزینهٔ **Saman OS (Live)** را بزن. دسکتاپ زنده بالا
  می‌آید؛ این‌جا هنوز چیزی نصب نشده و می‌توانی همه‌چیز را امتحان کنی.

### ۳) نصب کنار ویندوز

- یک ترمینال باز کن (برنامهٔ Terminal در منوی برنامه‌ها).
- اول نام دیسکت را پیدا کن:

```
lsblk
```

دیسکی که پارتیشن‌های ویندوز (ntfs) روی آن است معمولاً `sda` یا
`nvme0n1` است.

- حالا نصاب را اجرا کن (به‌جای `sda` نام دیسک خودت):

```
sudo saman-install --alongside /dev/sda
```

- نصاب پارتیشن EFI موجود را پیدا می‌کند (هرگز فرمتش نمی‌کند)، در فضای
  خالی یک پارتیشن تازه برای Saman OS می‌سازد، سیستم را کپی می‌کند و
  بوت‌لودر GRUB را نصب می‌کند. اگر روی همان پارتیشن EFI پوشهٔ ویندوز
  باشد، گزینهٔ **Windows** هم به منوی بوت اضافه می‌شود.
- برای اطمینان، نصاب از تو می‌خواهد نام دیسک را یک بار دیگر بنویسی.
- وقتی پیام «نصب تمام شد» آمد، سیستم را راه‌اندازی مجدد کن و فلش را بکش.

### ۴) انتخاب سیستم موقع بوت

از این به بعد موقع روشن‌کردن، منوی GRUB می‌آید:

- **Saman OS** — ورود به Saman OS (کاربر: `saman`، رمز: `saman`؛ بعد از
  اولین ورود حتماً با دستور `passwd` رمز را عوض کن).
- **Windows** — ورود به ویندوز.

اگر منو نیامد، از منوی بوت خود سیستم (F12) می‌توانی بین «SamanOS» و
«Windows Boot Manager» انتخاب کنی؛ ویندوز سر جایش است.

## نصب روی دیسک خالی

اگر دیسک جدا و خالی داری، نصب کامل ساده‌تر است (هشدار: **همهٔ داده‌های
آن دیسک پاک می‌شود**):

```
sudo saman-install /dev/sdX
```

نصاب روی دیسک پارتیشن‌بندی کامل می‌سازد (بوت BIOS و UEFI هر دو) و سیستم
را نصب می‌کند.

## به‌روزرسانی

داخل Saman OS، به‌روزرسانی از انتشارهای گیت‌هاب گرفته می‌شود:

```
saman-updater check            # بررسی نسخهٔ تازه
sudo saman-updater install     # نصب (با راستی‌آزمایی هش و پشتیبان‌گیری)
sudo saman-updater rollback    # برگشت به نسخهٔ قبل، اگر لازم شد
```

## حذف Saman OS

- در ویندوز، Disk Management را باز کن و پارتیشن Saman OS (با برچسب
  SAMANOS) را حذف کن؛ فضای آزادشده را می‌توانی به درایو C برگردانی
  (Extend Volume).
- پوشهٔ `SamanOS` را از پارتیشن EFI پاک کن (اختیاری؛ بدون آن هم ویندوز
  مثل قبل بوت می‌شود).
