# بوت Saman OS 3.1 از روی دیسک داخلی ویندوز (بدون فلش) — با GRUB2Win

از نسخهٔ ۳٫۱، لودر Saman OS می‌تواند فایل ISO را از روی یک پارتیشن
داخلی (NTFS/FAT/exFAT) پیدا کند و از همان‌جا بوت شود؛ دیگر فلش لازم
نیست. این راهنما برای نصب کنار ویندوز روی همان دیسک است.

## پیش‌نیازها (همه با دسترسی Administrator)

1. در ویندوز، روی برنامه‌ها «Run as administrator» بزنید؛ نشست عادی
   برای تغییر بوت و پارتیشن کافی نیست.
2. از پارتیشن E: (یا هر پارتیشنی که جا دارد) در Disk Management
   حداقل ۲۴ گیگابایت — پیشنهاد ما ۱۲۰ گیگابایت — Shrink کنید تا
   فضای «Unallocated» ساخته شود. به این فضا دست نزنید؛ نصاب Saman OS
   خودش آن را پیدا می‌کند.
3. GRUB2Win را نصب و اجرا کنید (Administrator).

## آماده‌سازی

4. فایل `saman-os-3.1-live-amd64.iso` را در **ریشهٔ همان پارتیشنی**
   که از آن فضا کم کردید کپی کنید (مثلاً `E:\saman-os-3.1-live-amd64.iso`).
   اسم فایل را عوض نکنید.

## ساخت منوی بوت در GRUB2Win

5. در GRUB2Win یک ورودی تازه از نوع «Custom code» بسازید و این متن
   را بگذارید. به‌جای `gptX` شمارهٔ پارتیشنِ فایل ISO را بنویسید
   (راهنمای پیدا کردنش پایین آمده):

```
menuentry "Saman OS 3.1 (from disk)" {
    set isofile="/saman-os-3.1-live-amd64.iso"
    loopback loop (hd0,gptX)$isofile
    linux (loop)/casper/vmlinuz boot=live saman_iso=$isofile
    initrd (loop)/casper/initrd.img
}
```

6. تغییرات را Save کنید و ری‌استارت کنید؛ از منوی بوت، ورودی
   Saman OS را انتخاب کنید. دسکتاپ زنده بالا می‌آید.

## پیدا کردن شمارهٔ پارتیشن

در منوی GRUB کلید `c` را بزنید تا خط فرمان باز شود؛ بنویسید `ls`
تا دیسک‌ها و پارتیشن‌ها فهرست شوند. برای هر کدام مثلاً
`ls (hd0,gpt4)/` را بزنید؛ پارتیشنی درست است که فایل
`saman-os-3.1-live-amd64.iso` در فهرستش دیده شود. با `Esc` برگردید.

## نصب

7. در دسکتاپ زنده، نصاب را اجرا کنید و گزینهٔ «نصب کنار ویندوز» را
   بزنید؛ نصاب فضای خالیِ ساخته‌شده را پیدا می‌کند. پارتیشنی که
   فایل ISO روی آن است دست نخورده می‌ماند.

نکته: اگر بوت نشد، از صفحه عکس بگیرید و بفرستید؛ پیام‌های لودر
(خط‌هایی که با `[loader]` شروع می‌شوند) دقیق می‌گویند کجا ایستاده
است.
